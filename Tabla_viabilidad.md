# El problema identificado:

Durante las reuniones con el grupo sobre a que problematica intentar resolver mediente la programacion, todos coincidimos con algo, y es que las citas medicas tarden una eternidad en agendarse y recibirlas.
La idea planteada como grupo es la creacion y desarrolo que una aplicacion que permita tanto al usuario como al doctor, agendar dicha cita con tiempo previo, ademas de recordatorios y confirmaciones para ambas partes, confirmando de esta manera la disponibilidad en ambas partes involcradas

Por ello la siguiente tabla es para demostrar que de este tema se puede desarrollar una aplicacion y posible solucion a la problematica

# Justificación de la viabilidad del tema

El tema es viable porque permite desarrollar una solución de software sobre la cual se pueden realizar pruebas y obtener evidencia directamente relacionada con el problema de investigación. El proyecto permite trabajar con información de clientes, profesionales, servicios y citas sin depender de sistemas externos a los que el equipo no tenga acceso.

Asimismo, las características del sistema permiten definir variables medibles, como tiempos de respuesta, cantidad de registros procesados, número de casos de prueba ejecutados y errores detectados. Esto facilita que los resultados obtenidos durante las siguientes etapas puedan ser registrados, comparados y analizados de manera objetiva.
